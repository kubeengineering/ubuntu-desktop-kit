# Ubuntu Desktop Kit

Один скрипт, который превращает свежепоставленную Ubuntu 24.04 в настроенный десктоп: тёмная тема, виджет на рабочем столе, обои с автоматической палитрой под картинку, набор терминальных утилит и горячие клавиши.

Запускается на чистой системе, отрабатывает за 10–15 минут, ничего не спрашивает кроме пароля в начале.

> Проект собран из реального вечера настройки — всё, что здесь есть, проверено на ThinkPad с двумя мониторами. По мере использования дополняется.

## Часть 1. Ставим Ubuntu

Если система уже стоит — пропускай, переходи к части 2.

### Загрузочная флешка

**Понадобится:** флешка от 8 ГБ (данные с неё сотрутся) и образ Ubuntu.

1. Скачай ISO с [ubuntu.com/download/desktop](https://ubuntu.com/download/desktop) — бери **24.04 LTS**, поддержка до 2029 года.

2. Запиши образ на флешку:

   | Система | Программа |
   |---|---|
   | Windows | [Rufus](https://rufus.ie) — выбрать ISO, схема GPT, файловая система FAT32, «Записать в ISO-образ режиме» |
   | Linux | `sudo dd if=ubuntu-24.04.iso of=/dev/sdX bs=4M status=progress oflag=sync` (посмотри букву через `lsblk`) |
   | macOS | [balenaEtcher](https://etcher.balena.io) |

   Кроссплатформенно и без риска ошибиться с буквой диска — **balenaEtcher**, он работает везде одинаково.

3. Загрузись с флешки: при включении жми `F12` / `F2` / `Del` (зависит от производителя) и выбери USB в списке загрузки.

   На ноутбуках Lenovo — `F12`, на HP — `F9`, на Dell — `F12`, на большинстве материнок — `Del` для BIOS и `F11`/`F8` для boot menu.

### Установка

Мастер простой, важны три момента:

- **Тип установки** — если ставишь рядом с Windows, выбирай «Установить рядом», иначе «Стереть диск». Второй вариант удаляет всё.
- **Шифрование диска** — на рабочем ноутбуке стоит включить. Пароль будет спрашиваться при каждой загрузке.
- **Обновления при установке** — включи «Загрузить обновления», сэкономит время потом.

После установки, перед запуском скрипта:

```bash
sudo apt update && sudo apt upgrade -y
```

## Часть 2. Разворачиваем кастомизацию

```bash
wget https://raw.githubusercontent.com/kubeengineering/ubuntu-desktop-kit/main/bootstrap.sh
```

```bash
chmod +x bootstrap.sh
```

```bash
./bootstrap.sh
```

Пароль спросит один раз в начале. Единственный вопрос, который может задать: если сессия Wayland — предложит переключить вход по умолчанию на Xorg (см. раздел «Wayland или Xorg» ниже). Флаги, чтобы не спрашивал:

```bash
./bootstrap.sh --xorg           # сразу переключить на Xorg
./bootstrap.sh --keep-wayland   # остаться на Wayland без вопроса
```

**Скрипт идемпотентный** — если что-то пошло не так, просто запусти заново. Повторный прогон не сломает уже сделанное: увидит установленные пакеты, скачанные обои, существующие конфиги и пропустит их.

**Все скрытые операции пишутся в лог** `~/.cache/ubuntu-kit-bootstrap.log` — если какая-то секция показала ✗, причина там. В конце скрипт печатает счётчик проблем.

### После запуска

1. **Перелогинься** — иначе не подхватятся тема, расширения и алиасы
2. Открой **Extension Manager** и покрути под себя Blur My Shell, Dash to Panel, Just Perfection
3. **Settings → Online Accounts** — подключи почту, календарь появится в панели

## Wayland или Xorg

Свежая Ubuntu 24.04 по умолчанию входит в **Wayland** (кроме машин с проприетарным драйвером NVIDIA — те остаются на Xorg). А этот набор X11-нативный:

| Компонент | На Wayland |
|---|---|
| Виджет Conky | может быть невидим после логина (гонка XWayland) |
| rofi | открывается, но может не принимать клавиатуру |
| Пипетка (gpick) | не работает вообще — Wayland запрещает читать чужие пиксели |
| Скриншот по хоткею | скрипт сам оборачивает команду, но flameshot на Wayland капризен |

Поэтому при запуске из Wayland-сессии скрипт предлагает сделать Xorg сессией по умолчанию (правит `WaylandEnable=false` в `/etc/gdm3/custom.conf`, вступает в силу после перезагрузки). Это стандартный документированный переключатель, откатывается обратно комментированием той же строки.

Не хочешь трогать — можно каждый раз выбирать «Ubuntu on Xorg» шестерёнкой на экране входа. Цена Xorg: нет пофракционного масштабирования на мониторе и части жестов тачпада.

## Что именно делает скрипт

Одиннадцать секций, каждую видно в выводе.

### 1. Пакеты

| Пакет | Зачем |
|---|---|
| `conky-all` | виджет на рабочем столе |
| `rofi` | меню запуска приложений по хоткею |
| `flameshot` | скриншоты с редактором |
| `feh`, `imagemagick` | работа с обоями и палитрой |
| `lsd`, `bat` | `ls` с иконками, `cat` с подсветкой |
| `ranger` | файловый менеджер в терминале |
| `btop` | монитор ресурсов |
| `zathura` | лёгкий PDF-ридер |
| `calcurse` | календарь и задачи в терминале |
| `gpick`, `xclip` | пипетка цвета |
| `mat2` | очистка метаданных из файлов |
| `gnome-keyring` | хранилище паролей |
| `sassc` | сборка темы Tokyo Night из исходников |
| `gnome-shell-extensions` | расширение user-theme из репозитория, а не с сайта |
| `gir1.2-gtop-2.0`, `lm-sensors` | без них Vitals падает с ошибкой |

### 2. Шрифт

**JetBrainsMono Nerd Font** — моноширинный шрифт с тремя тысячами иконок. Без него виджеты и панели показывают квадраты вместо значков.

Ставится в `~/.local/share/fonts`, без прав root.

### 3. Тема

**Tokyo Night** — тёмная тема GTK. Важная деталь: в репозитории темы **нет готовых файлов** — скрипт собирает её из исходников её же `install.sh` (потому и нужен `sassc`). Флаг `-l` при сборке линкует тему в `~/.config/gtk-4.0`, иначе новые GTK4-приложения (Настройки, Nautilus) остались бы стандартными. Тема ставится и на оболочку GNOME через user-theme.

### 4. pywal16

Главная магия: анализирует обои, вытаскивает 16 доминирующих цветов и раскладывает их по конфигам. Терминал, виджет и рамки окон становятся в тон картинке.

Оригинальный `pywal` заброшен автором в 2024, здесь используется живой форк.

### 5. Расширения GNOME

Ставятся автоматически через `gext --filesystem` (без единого диалога — dbus-вариант показывал бы окно подтверждения на каждое):

| Расширение | Что даёт |
|---|---|
| Blur My Shell | размытие панели и overview |
| Dash to Panel | панель задач как в Windows, настраиваемая |
| Just Perfection | убрать лишние элементы оболочки |
| Vitals | температура и загрузка в панели |
| User Themes | возможность менять тему самой оболочки (из apt-пакета) |

Заодно скрипт **отключает штатный Ubuntu Dock** — иначе после релогина он повис бы поверх Dash to Panel, и выглядело бы это как «скрипт сломал рабочий стол». Вернуть: `gnome-extensions enable ubuntu-dock@ubuntu.com`.

Активируются расширения после релогина — это нормально.

### 6. Обои

**Определяет родное разрешение панели** через `/sys/class/drm` (работает и на Wayland, и по SSH — в отличие от xrandr, который на Wayland врёт при масштабировании) и качает подходящие с [wallhaven.cc](https://wallhaven.cc) по восьми темам: природа, минимализм, космос, горы, тёмные, город, абстракция, лес.

Битые загрузки и HTML-страницы ошибок отсеиваются по mime-типу, недокачанные файлы curl удаляет сам (`--remove-on-error`).

Отсеивает всё тяжелее 12 МБ — на глаз разницы нет, а место экономит.

### 7. Скрипты в `~/bin`

| Скрипт | Что делает |
|---|---|
| `setwall` | смена обоев с историей, закреплением и избранным |
| `weather-line` | погода через wttr.in, по-русски |
| `conky-recolor` | перекрашивает виджет под текущую палитру |
| `powermenu` | меню выключения через rofi |
| `wifimenu` | выбор сети через rofi |
| `pickcolor` | пипетка: тычешь в пиксель, hex в буфере |
| `cleanmeta` | сносит EXIF и прочие метаданные из файлов |

### 8. Виджет Conky

Часы, дата, погода, загрузка процессора и памяти, скорость сети, индикатор VPN.

**Сам подставляет имя твоего Wi-Fi интерфейса** — на разных машинах он называется по-разному (`wlp0s20f3`, `wlan0`, `wlp2s0`).

Добавляется в автозапуск.

### 9. Алиасы

```bash
ls    → lsd          # с иконками
ll    → lsd -l
lt    → lsd --tree   # дерево каталогов
c     → batcat       # cat с подсветкой синтаксиса
r     → ranger_cd    # ranger, который оставляет тебя в открытом каталоге
walls                # сколько обоев в коллекции
```

`ranger_cd` — важная мелочь: обычный ranger при выходе возвращает туда, откуда запустили. Эта обёртка оставляет в том каталоге, куда дошёл.

### 10. Настройки GNOME

Тёмная тема, иконки Papirus, шрифт, шесть фиксированных рабочих столов вместо динамических, тап тачпадом.

### 11. Горячие клавиши

Прописываются через `dconf`, руками ничего вбивать не надо. Перед этим скрипт освобождает два занятых системой сочетания:

- **Super+P** — по умолчанию переключает конфигурацию мониторов (остаётся на Fn-клавише дисплея)
- **Super+D** — в Ubuntu сворачивает все окна (остаётся на Ctrl+Super+D)

Обои сознательно повешены на **Super+R**, а не Ctrl+R: глобальный перехват Ctrl+R отобрал бы обновление страницы у браузера и reverse-search у терминала.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Super+D` | меню приложений (rofi) |
| `Super+Shift+S` | скриншот с выделением области |
| `Super+R` | следующие обои |
| `Super+Shift+R` | предыдущие обои |
| `Super+P` | закрепить обои (перестают меняться) |
| `Super+F` | добавить в избранное |
| `Super+Shift+F` | случайная из избранного |
| `Super+X` | меню питания |
| `Super+W` | выбор Wi-Fi сети |
| `Super+Shift+C` | пипетка цвета |
| `Super+C` | календарь |

В терминале: `r` — ranger, `c file` — просмотр с подсветкой, `walls` — счётчик обоев.

## Настройка под себя

### Другой город в погоде

```bash
sed -i 's/CITY="Moscow"/CITY="Saint Petersburg"/' ~/bin/weather-line
```

### Подвинуть виджет

В `~/.config/conky/main.conf`:

- `alignment` — угол привязки: `top_right`, `top_left`, `bottom_right`, `bottom_left`, `top_middle`
- `gap_x`, `gap_y` — отступ от угла в пикселях

```bash
pkill conky && conky -c ~/.config/conky/main.conf &
```

### Плотность подложки виджета

```bash
sed -i 's/own_window_argb_value = .*/own_window_argb_value = 180,/' ~/.config/conky/main.conf
```

`0` — совсем прозрачно, `255` — сплошной фон. Дефолт `225`.

### Больше обоев

```bash
cd ~/Pictures/wallpapers
for q in sunset ocean snow neon japan architecture; do
  curl -s "https://wallhaven.cc/api/v1/search?q=$q&atleast=1920x1080&categories=100&purity=100&sorting=views" | jq -r '.data[].path'
  sleep 2
done | grep '\.jpg$' | sort -u | xargs -n1 -P3 curl -sO
```

Вместо `1920x1080` подставь своё разрешение. Темы — любые слова, работает поиск wallhaven.

### Прозрачная панель

Настройки Dash to Panel → **Style** → `Panel background opacity` → `0`

Если панель на нескольких мониторах — настройки задаются **отдельно для каждого**, монитор выбирается на вкладке Position.

## Откат

Полностью убрать всё, что сделал скрипт:

```bash
gsettings reset-recursively org.gnome.desktop.interface
pkill conky
rm -rf ~/.config/conky ~/.config/autostart/conky.desktop
rm -rf ~/bin/{setwall,weather-line,conky-recolor,powermenu,wifimenu,pickcolor,cleanmeta}
rm -rf ~/.cache/wal ~/.cache/wall*
dconf reset -f /org/gnome/settings-daemon/plugins/media-keys/
```

Алиасы — вручную убрать блок `# --- bootstrap aliases ---` из `~/.bashrc`.

Пакеты остаются, они безвредны. Хочешь снести:

```bash
sudo apt purge -y conky-all rofi flameshot lsd bat ranger zathura calcurse gpick mat2
```

## Если что-то не работает

**Первое: смотри лог** `~/.cache/ubuntu-kit-bootstrap.log` — туда пишется всё, что скрыто с экрана.

**apt упал в самом начале** — на свежей системе первые минуты фоновые обновления держат менеджер пакетов. Скрипт ждёт до 10 минут сам; если не дождался — подожди и перезапусти.

**Расширения не поставились** — `extensions.gnome.org` бывает недоступен из корпоративных сетей. Ставь вручную через Extension Manager, он ходит другим путём.

**Обои не скачались** — проверь, что API отвечает:
```bash
curl -s "https://wallhaven.cc/api/v1/search?q=nature" | jq '.data | length'
```
Должно вернуть `24`.

**Виджет не видно** — запусти в терминале и посмотри вывод:
```bash
pkill conky; conky -c ~/.config/conky/main.conf
```

**Погода пустая** — проверь wttr.in:
```bash
curl "wttr.in/Moscow?format=3"
```

**Хоткеи не сработали** — проверь, что зарегистрировались:
```bash
gsettings get org.gnome.settings-daemon.plugins.media-keys custom-keybindings
```
Должен вывестись список из одиннадцати путей. Если пусто — перелогинься.

**Тема не применилась** — проверь, что она собралась:
```bash
ls ~/.themes | grep Tokyonight
```
Пусто — сборка упала, смотри лог (обычно не хватило `sassc` или не было сети для клона).

**Алиасы не работают** — перечитай конфиг:
```bash
source ~/.bashrc
```
