# Ubuntu Desktop Kit

Один скрипт, который превращает свежепоставленную Ubuntu 24.04 в настроенный десктоп: тёмная тема, виджет на рабочем столе, обои с автоматической палитрой под картинку, набор терминальных утилит и горячие клавиши.

Запускается на чистой системе, отрабатывает за 10–15 минут, ничего не спрашивает кроме пароля в начале.

> Проект собран из реального вечера настройки — всё, что здесь есть, проверено на ThinkPad с двумя мониторами. По мере использования дополняется.

## Часть 1. Ставим Ubuntu

Если система уже стоит — пропускай, переходи к части 2.

> Ставишь на **подержанный ноутбук**? Сначала пройди [чек-лист проверки б/у](docs/thinkpad-x13-gen2.md) — BIOS-замки, память, диск, батарея. Написан под ThinkPad X13 Gen 2, но этапы подходят любому ноутбуку.

### Шаг 1. Скачать образ

Иди на [ubuntu.com/download/desktop](https://ubuntu.com/download/desktop) и бери **Ubuntu 24.04 LTS** (Long Term Support — обновления до 2029 года). Файл называется `ubuntu-24.04.x-desktop-amd64.iso`, весит ~6 ГБ.

Не бери промежуточные выпуски (24.10, 25.04 и т.п.) — они живут по 9 месяцев и скрипт на них не проверялся.

**Проверь, что образ скачался целым** — битый ISO даёт самые загадочные ошибки установки:

```powershell
# Windows (PowerShell):
Get-FileHash .\ubuntu-24.04.3-desktop-amd64.iso -Algorithm SHA256
```
```bash
# Linux / macOS:
sha256sum ubuntu-24.04.3-desktop-amd64.iso
```

Полученную строку сравни с суммой на странице загрузки (ссылка «verify your download»). Совпала — образ целый.

### Шаг 2. Записать флешку

**Понадобится:** флешка **от 8 ГБ**. Всё, что на ней есть, будет стёрто. USB 3.0 (синий разъём) заметно быстрее.

| Система | Как |
|---|---|
| **Windows** | [Rufus](https://rufus.ie): выбрать флешку → выбрать ISO → схема разделов **GPT**, целевая система **UEFI (non-CSM)** → Старт. На вопрос про режим записи — **«Записать в ISO-образ режиме»** (по умолчанию). |
| **Linux** | `lsblk` — найди флешку (например `sdb`, смотри по размеру!), затем: `sudo dd if=ubuntu-24.04.3-desktop-amd64.iso of=/dev/sdb bs=4M status=progress oflag=sync`. **Буква диска — самое опасное место: перепутаешь — сотрёшь не тот диск.** |
| **macOS** | [balenaEtcher](https://etcher.balena.io): три кнопки, ошибиться негде. |

Если сомневаешься — бери **balenaEtcher**, он есть под все три системы и не даёт выстрелить себе в ногу.

### Шаг 3. Загрузиться с флешки

1. Воткни флешку, перезагрузи ноутбук.
2. Сразу при включении долби клавишу boot-меню:

   | Производитель | Boot-меню | BIOS/UEFI |
   |---|---|---|
   | Lenovo | `F12` | `F1` / `F2` |
   | HP | `F9` | `F10` |
   | Dell | `F12` | `F2` |
   | ASUS | `Esc` / `F8` | `F2` / `Del` |
   | Acer | `F12` | `F2` |
   | MSI | `F11` | `Del` |
   | Самосбор (материнки) | `F11` / `F8` | `Del` |

3. В списке выбери свою флешку (строка с «UEFI: имя_флешки»).
4. В меню GRUB выбери **Try or Install Ubuntu**.

### Если что-то не так на этом этапе

**Флешки нет в boot-меню** → в BIOS проверь, что USB Boot включён, а флешка записана в GPT/UEFI-режиме (шаг 2).

**Установщик не видит диск (самая частая проблема на новых ноутбуках).** В BIOS накопитель работает в режиме Intel RST/VMD (RAID), которого Linux-установщик не понимает. Зайди в BIOS → найди **SATA Mode / VMD / Storage Configuration** → переключи на **AHCI**.
⚠️ Если на диске уже стоит Windows — она после этого может не загрузиться без переключения обратно. Для чистой установки (стираем всё) — переключай смело.

**Secure Boot** — выключать **не нужно**: Ubuntu подписана и грузится с ним. Единственное следствие: если поставишь галку про сторонние драйверы (NVIDIA), установщик попросит задать пароль MOK — задай простой, при следующей загрузке появится синий экран **MOK Management** → выбери **Enroll MOK** → введи этот пароль. Это одноразовая процедура.

**Ставишь рядом с Windows (dual boot)** — два обязательных действия в Windows ДО установки:
1. Отключи BitLocker (Параметры → Конфиденциальность и защита → Шифрование устройства), иначе разделы не подвинуть.
2. Отключи быстрый запуск: Панель управления → Электропитание → «Действия кнопок питания» → снять «Включить быстрый запуск». Иначе Windows держит диск заблокированным.

### Шаг 4. Установка

Мастер проведёт по шагам, важные точки:

1. **Язык** — какой удобен. Совет: **English** + русская раскладка добавится позже. С английской системой проще гуглить ошибки, а скрипт из части 2 всё равно русифицирует погоду и виджет. (На русской системе всё тоже работает — скрипт понимает каталог `~/Изображения`.)
2. **Подключись к Wi-Fi** — установщик докачает свежие пакеты.
3. **Installation type** → «Interactive installation».
4. **Applications** → «Default selection» достаточно.
5. Поставь **обе галки**: «Install third-party software for graphics and Wi-Fi hardware» и «Download and install support for additional media formats». Первая критична для NVIDIA и части Wi-Fi карт.
6. **Disk setup**:
   - Чистая установка → **Erase disk and install Ubuntu** (стирает ВСЁ на диске)
   - Рядом с Windows → **Install Ubuntu alongside Windows**
   - **Шифрование** (Advanced features → LVM + encryption) — на рабочем ноутбуке стоит включить. Пароль будет спрашиваться при каждом включении, потерять его = потерять данные.
7. Создай пользователя. Имя — маленькими латинскими буквами, без пробелов.
8. Дождись конца, вытащи флешку, перезагрузись.

### Шаг 5. Первая загрузка

1. Залогинься, закрой приветственный мастер (Skip/Next до конца).
2. Открой терминал: `Ctrl+Alt+T`.
3. Обнови систему до конца:

```bash
sudo apt update && sudo apt upgrade -y
```

4. Если ставил галку про сторонние драйверы на NVIDIA-ноутбуке — проверь, что драйвер встал:

```bash
nvidia-smi
```

Таблица с видеокартой — всё хорошо. `command not found` — открой «Additional Drivers» (Software & Updates → вкладка Additional Drivers) и выбери проприетарный драйвер, перезагрузись.

5. Перезагрузись ещё раз (после upgrade могло приехать ядро) — и переходи к части 2.

## Часть 2. Разворачиваем кастомизацию

```bash
wget https://raw.githubusercontent.com/kubeengineering/ubuntu-desktop-kit/main/bootstrap.sh
```

```bash
chmod +x bootstrap.sh
```

```bash
./bootstrap.sh
```

Пароль спросит один раз в начале. Единственный вопрос, который может задать: если сессия Wayland — предложит переключить вход по умолчанию на Xorg (см. раздел «Wayland или Xorg» ниже). Флаги, чтобы не спрашивал:

```bash
./bootstrap.sh --xorg           # сразу переключить на Xorg
./bootstrap.sh --keep-wayland   # остаться на Wayland без вопроса
```

**Скрипт идемпотентный** — если что-то пошло не так, просто запусти заново. Повторный прогон не сломает уже сделанное: увидит установленные пакеты, скачанные обои, существующие конфиги и пропустит их.

**Все скрытые операции пишутся в лог** `~/.cache/ubuntu-kit-bootstrap.log` — если какая-то секция показала ✗, причина там. В конце скрипт печатает счётчик проблем.

### После запуска

1. **Перелогинься** — иначе не подхватятся тема, расширения и алиасы
2. Открой **Extension Manager** и покрути под себя Blur My Shell, Dash to Panel, Just Perfection
3. **Settings → Online Accounts** — подключи почту, календарь появится в панели

## Часть 3. desktop-kit — один инструмент на всё

Всё, что раньше было россыпью модулей, собрано в один скрипт с подкомандами. Его и стоит держать под рукой: правится один файл, а не восемь.

```bash
./desktop-kit.sh help              список команд
./desktop-kit.sh help buttons      все параметры одной команды
./desktop-kit.sh status            что сейчас применено
./desktop-kit.sh selftest          проверить себя и собрать архив с логами
./desktop-kit.sh revert            вернуть как было
```

| Команда | Что настраивает |
|---|---|
| `buttons` | кнопки заголовка: размер, значки, подсветка, цвет закрытия |
| `corners` | скругление углов окон, меню и подсказок |
| `theme` | тема оформления и цветовая схема; отсутствующую предложит собрать |
| `icons` | тема значков, цвет папок |
| `font` | шрифт интерфейса и моноширинный |
| `widget` | виджет conky: скругление, цвет, плотность |
| `terminal` | GNOME Terminal: прозрачность, шрифт, палитра pywal |
| `newtab` | страница новой вкладки Chrome и её ярлыки |
| `wallpapers` | банк обоев: пополнение, расписание, чистка |
| `wall` | сменить обои: следующие, предыдущие, случайные |
| `serve` | отдать локальную апку по `http://localhost` |
| `keys` | горячие клавиши: показать, добавить, снять |
| `panel` | панель задач Dash to Panel: прозрачность, высота |
| `app` | своя тема для одного приложения |
| `audit` | полный снимок системы |

Глобальные параметры работают с любой командой: `--dry-run` рассказывает, что было бы сделано, ничего не меняя; `--yes` не переспрашивает; `--quiet` пишет только в лог.

**Каждое изменение обратимо.** Исходное значение запоминается при первом изменении, а не берётся из умолчаний системы, так что `revert` вернёт именно то, что было. Файлы (`gtk.css`, конфиг conky, список ссылок) копируются до первой правки — и копия снимается только с ещё нетронутого файла, иначе повторный запуск сохранил бы уже изменённое.

**Правки не мешают друг другу**: каждая подсистема пишет свой помеченный блок, поэтому `corners` не затирает `buttons`, а чужие правила в `gtk.css` переживают и установку, и откат.

Пополнение банка обоев вешается на расписание этой же командой:

```bash
./desktop-kit.sh wallpapers --timer Wed 13:00
```

Скрипт копирует себя в `~/bin/desktop-kit` и ссылается туда, так что скачанный файл можно потом удалить.

### Самопроверка

```bash
./desktop-kit.sh selftest          # ничего не меняет
./desktop-kit.sh selftest --full   # плюс применение и откат каждой подсистемы
```

Безопасный режим проверяет окружение, разбор аргументов, доступность wallhaven и репозитория значков, читаемость кэша значков Chrome, состояние `gtk.css` (в том числе на `!important` и на симлинк темы), банк обоев и `systemd --user`.

Полный режим дополнительно применяет и откатывает каждую подсистему **в отдельном временном доме** — живые настройки при этом не трогаются. Так было не всегда: первая версия честно делала `revert all` на живой машине и уносила настройки в состояние до первого запуска.

В конце рядом ложится `~/desktop-kit-selftest.tar.gz` — отчёт, лог, копии обоих `gtk.css` и снимок исходных значений. Архив можно переслать целиком, секреты в нём заменены на `<скрыто>`.

### Установка отсутствующей темы

```bash
./desktop-kit.sh theme --install Graphite-Light
```

Скрипт клонирует репозиторий вендора и собирает нужный вариант. Установщики вендоров называют каталог по-своему (`Graphite-Light`, `Graphite-light`, иногда с суффиксом варианта), поэтому имя не угадывается: список тем снимается до и после сборки, и применяется то, что реально появилось.

### Старые модули

Они остаются в `modules/` как рабочие и самодостаточные, но развивается теперь `desktop-kit.sh` — новые возможности появляются в нём.

### Новая вкладка Chrome

```bash
./modules/newtab.sh
```

Часы, свои ярлыки и обои фоном — причём **не та картинка, что на рабочем столе**. Фон запоминается между вкладками и перезапусками, листается стрелками `←` `→`.

Значки плиток берутся из локального кэша Chrome, поэтому внутренние адреса показываются настоящими иконками, а не заглушкой с буквой. Раз найденный значок запоминается в `icons.json` и больше не теряется, даже если в следующий раз база браузера промолчит.

Ярлыки при первом запуске подтягиваются из самого Chrome (плитки новой вкладки, Top Sites, закладки, история), дальше правятся руками:

```bash
nano ~/.local/share/newtab/links.txt
```

Чтобы страница встала на новую вкладку, нужно расширение — Chrome иначе не даёт. Ставится политикой:

```bash
sudo ./modules/chrome-policy.sh
```

Подробности, ручной путь и все размеры-шрифты — в [modules/chrome.md](modules/chrome.md). Там же главная грабля: без **Allow access to file URLs** будет белый экран.

Пересобирать после смены обоев или правки ссылок — тем же вызовом `newtab.sh`.

### Банк обоев

```bash
./modules/wallpapers.sh              # добрать 10
./modules/wallpapers.sh init         # первая заливка, 250 штук
./modules/wallpapers.sh timer        # каждую среду в 13:00
./modules/wallpapers.sh status       # банк, расписание, последние запуски
```

| Команда | Что делает |
|---|---|
| `add 25` | добрать 25 картинок сейчас |
| `init` | первая заливка на чистой системе |
| `timer` | расписание: среда, 13:00, по 10 штук |
| `timer Fri 19:00` | свой день и время |
| `timer Tue,Fri` | дважды в неделю |
| `timer off` | снять расписание, банк и скрипт остаются |
| `status` | сколько картинок, когда следующий запуск, последние запуски |
| `prune 900` | оставить 900 самых свежих (спросит подтверждение) |
| `urls` | показать, какие запросы уйдут на wallhaven |

Качает рисованное — digital art, artwork, illustration и родственные темы — под родное разрешение монитора, определённое через `/sys/class/drm`. Половина запросов идёт случайной выдачей, половина — лучшим за год, поэтому в банк попадает и новое, и проверенное.

Набор тем и seed привязаны к номеру недели: внутри недели повторный запуск даёт ту же выдачу, следующая неделя приносит совсем другую. Уже скачанное не перекачивается, битые файлы и всё тяжелее 12 МБ выбрасывается, страница новой вкладки пересобирается сама.

Среда, а не выходные: рабочий ноутбук включён с понедельника по пятницу, а на выходных `Persistent` просто откладывал бы запуск до понедельника. Пропуск всё равно догоняется — если машина была выключена, пополнение случится при следующем входе.

Расписание ставит скрипт в `~/bin/wallpapers` и ссылается туда, так что скачанный файл можно потом удалить. Каждый запуск пишется в `~/.local/state/wallpapers.log`, по завершении всплывает уведомление.

Первичная заливка на чистой системе — `./modules/wallpapers.sh --init` (~250 штук).

### Кнопки заголовка окна

```bash
./modules/titlebuttons.sh          # кнопка 32px, значок 18px
./modules/titlebuttons.sh 36 20    # свои размеры
./modules/titlebuttons.sh --revert # вернуть как было
```

Крупные тонкие кнопки вместо мелких с круглой подложкой. Кнопку рисуют **два независимых источника**: форму значка даёт тема иконок, размер и подложку — тема GTK, поэтому правится и то, и другое.

Papirus своих кнопок заголовка не содержит — GNOME подставляет запасные из Adwaita. Скрипт создаёт тему `Papirus-Fluent-Titlebar`, которая наследует Papirus целиком и переопределяет ровно четыре значка, взятых из Fluent. Папки и приложения остаются папирусными, обновления Papirus правки не затирают.

Размер пишется в `~/.config/gtk-3.0/gtk.css` и `gtk-4.0/gtk.css` блоком с маркерами: повторный запуск его заменяет, `--revert` вычищает, а чужие правила в этих файлах не трогаются.

⚠️ На Chrome, Tabby и Telegram не подействует — это Electron, они рисуют кнопки сами.

### Смена обоев по порядку

```bash
./modules/setwall.sh              # следующая по списку
./modules/setwall.sh prev         # предыдущая по списку
./modules/setwall.sh random       # случайная
./modules/setwall.sh current      # какая стоит и её номер
```

Листает каталог по порядку — как стрелки на странице новой вкладки, а не «вернуть предыдущую показанную». Позиция запоминается **именем** файла, а не номером: банк пополняется каждую неделю, и номер бы съезжал при появлении новых картинок.

Заодно обновляет палитру pywal, перекрашивает под неё GNOME Terminal и пересобирает страницу новой вкладки, чтобы её фон не совпал с тем, что стоит на рабочем столе.

Ставится на клавиши через `bootstrap.sh`, либо вручную: `setwall` на следующую, `setwall prev` на предыдущую.

### Локальная апка по http

```bash
./modules/localapp.sh ~/путь/к/апке
```

Плитка с адресом `file://` на новой вкладке молча не открывается: страница живёт в контексте расширения, а Chrome запрещает уходить оттуда к локальным файлам, и «Allow access to file URLs» этого не снимает. Скрипт поднимает апку службой на `127.0.0.1`, убеждается, что она отвечает, и переписывает ссылку в `links.txt` на `http://localhost`.

Из сети апка недоступна — слушается только петлевой адрес.

### Светлая почта при тёмной системе

```bash
./modules/evolution-light.sh
```

Своей темы у Evolution нет, он берёт системную. Скрипт подставляет `GTK_THEME` в его ярлык — включая пункты контекстного меню дока, иначе «Написать письмо» открывало бы тёмное окно.

### Tabby

[modules/tabby.md](modules/tabby.md) — готовый конфиг прозрачности с плотной панелью вкладок, таблица плотности и разбор трёх ловушек, каждая из которых стоила вечера.

## Wayland или Xorg

Свежая Ubuntu 24.04 по умолчанию входит в **Wayland** (кроме машин с проприетарным драйвером NVIDIA — те остаются на Xorg). А этот набор X11-нативный:

| Компонент | На Wayland |
|---|---|
| Виджет Conky | может быть невидим после логина (гонка XWayland) |
| rofi | открывается, но может не принимать клавиатуру |
| Пипетка (gpick) | не работает вообще — Wayland запрещает читать чужие пиксели |
| Скриншот по хоткею | скрипт сам оборачивает команду, но flameshot на Wayland капризен |

Поэтому при запуске из Wayland-сессии скрипт предлагает сделать Xorg сессией по умолчанию (правит `WaylandEnable=false` в `/etc/gdm3/custom.conf`, вступает в силу после перезагрузки). Это стандартный документированный переключатель, откатывается обратно комментированием той же строки.

Не хочешь трогать — можно каждый раз выбирать «Ubuntu on Xorg» шестерёнкой на экране входа. Цена Xorg: нет пофракционного масштабирования на мониторе и части жестов тачпада.

## Что именно делает скрипт

Одиннадцать секций, каждую видно в выводе.

### 1. Пакеты

| Пакет | Зачем |
|---|---|
| `conky-all` | виджет на рабочем столе |
| `rofi` | меню запуска приложений по хоткею |
| `flameshot` | скриншоты с редактором |
| `feh`, `imagemagick` | работа с обоями и палитрой |
| `lsd`, `bat` | `ls` с иконками, `cat` с подсветкой |
| `ranger` | файловый менеджер в терминале |
| `btop` | монитор ресурсов |
| `zathura` | лёгкий PDF-ридер |
| `calcurse` | календарь и задачи в терминале |
| `gpick`, `xclip` | пипетка цвета |
| `mat2` | очистка метаданных из файлов |
| `gnome-keyring` | хранилище паролей |
| `sassc` | сборка темы Tokyo Night из исходников |
| `gnome-shell-extensions` | расширение user-theme из репозитория, а не с сайта |
| `gir1.2-gtop-2.0`, `lm-sensors` | без них Vitals падает с ошибкой |

### 2. Шрифт

**JetBrainsMono Nerd Font** — моноширинный шрифт с тремя тысячами иконок. Без него виджеты и панели показывают квадраты вместо значков.

Ставится в `~/.local/share/fonts`, без прав root.

### 3. Тема

**Tokyo Night** — тёмная тема GTK. Важная деталь: в репозитории темы **нет готовых файлов** — скрипт собирает её из исходников её же `install.sh` (потому и нужен `sassc`). Флаг `-l` при сборке линкует тему в `~/.config/gtk-4.0`, иначе новые GTK4-приложения (Настройки, Nautilus) остались бы стандартными. Тема ставится и на оболочку GNOME через user-theme.

### 4. pywal16

Главная магия: анализирует обои, вытаскивает 16 доминирующих цветов и раскладывает их по конфигам. Терминал, виджет и рамки окон становятся в тон картинке.

Оригинальный `pywal` заброшен автором в 2024, здесь используется живой форк.

### 5. Расширения GNOME

Ставятся автоматически через `gext --filesystem` (без единого диалога — dbus-вариант показывал бы окно подтверждения на каждое):

| Расширение | Что даёт |
|---|---|
| Blur My Shell | размытие панели и overview |
| Dash to Panel | панель задач как в Windows, настраиваемая |
| Just Perfection | убрать лишние элементы оболочки |
| Vitals | температура и загрузка в панели |
| User Themes | возможность менять тему самой оболочки (из apt-пакета) |

Заодно скрипт **отключает штатный Ubuntu Dock** — иначе после релогина он повис бы поверх Dash to Panel, и выглядело бы это как «скрипт сломал рабочий стол». Вернуть: `gnome-extensions enable ubuntu-dock@ubuntu.com`.

Активируются расширения после релогина — это нормально.

### 6. Обои

**Определяет родное разрешение панели** через `/sys/class/drm` (работает и на Wayland, и по SSH — в отличие от xrandr, который на Wayland врёт при масштабировании) и качает подходящие с [wallhaven.cc](https://wallhaven.cc) по восьми темам: природа, минимализм, космос, горы, тёмные, город, абстракция, лес.

Битые загрузки и HTML-страницы ошибок отсеиваются по mime-типу, недокачанные файлы curl удаляет сам (`--remove-on-error`).

Отсеивает всё тяжелее 12 МБ — на глаз разницы нет, а место экономит.

### 7. Скрипты в `~/bin`

| Скрипт | Что делает |
|---|---|
| `setwall` | смена обоев с историей, закреплением и избранным |
| `weather-line` | погода через wttr.in, по-русски |
| `conky-recolor` | перекрашивает виджет под текущую палитру |
| `powermenu` | меню выключения через rofi |
| `wifimenu` | выбор сети через rofi |
| `pickcolor` | пипетка: тычешь в пиксель, hex в буфере |
| `cleanmeta` | сносит EXIF и прочие метаданные из файлов |

### 8. Виджет Conky

Часы, дата, погода, загрузка процессора и памяти, скорость сети, индикатор VPN.

**Сам подставляет имя твоего Wi-Fi интерфейса** — на разных машинах он называется по-разному (`wlp0s20f3`, `wlan0`, `wlp2s0`).

Добавляется в автозапуск.

### 9. Алиасы

```bash
ls    → lsd          # с иконками
ll    → lsd -l
lt    → lsd --tree   # дерево каталогов
c     → batcat       # cat с подсветкой синтаксиса
r     → ranger_cd    # ranger, который оставляет тебя в открытом каталоге
walls                # сколько обоев в коллекции
```

`ranger_cd` — важная мелочь: обычный ranger при выходе возвращает туда, откуда запустили. Эта обёртка оставляет в том каталоге, куда дошёл.

### 10. Настройки GNOME

Тёмная тема, иконки Papirus, шрифт, шесть фиксированных рабочих столов вместо динамических, тап тачпадом.

### 11. Горячие клавиши

Прописываются через `dconf`, руками ничего вбивать не надо. Перед этим скрипт освобождает два занятых системой сочетания:

- **Super+P** — по умолчанию переключает конфигурацию мониторов (остаётся на Fn-клавише дисплея)
- **Super+D** — в Ubuntu сворачивает все окна (остаётся на Ctrl+Super+D)

Обои сознательно повешены на **Super+R**, а не Ctrl+R: глобальный перехват Ctrl+R отобрал бы обновление страницы у браузера и reverse-search у терминала.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Super+D` | меню приложений (rofi) |
| `Super+Shift+S` | скриншот с выделением области |
| `Super+R` | следующие обои |
| `Super+Shift+R` | предыдущие обои |
| `Super+P` | закрепить обои (перестают меняться) |
| `Super+F` | добавить в избранное |
| `Super+Shift+F` | случайная из избранного |
| `Super+X` | меню питания |
| `Super+W` | выбор Wi-Fi сети |
| `Super+Shift+C` | пипетка цвета |
| `Super+C` | календарь |

В терминале: `r` — ranger, `c file` — просмотр с подсветкой, `walls` — счётчик обоев.

## Настройка под себя

### Другой город в погоде

```bash
sed -i 's/CITY="Moscow"/CITY="Saint Petersburg"/' ~/bin/weather-line
```

### Подвинуть виджет

В `~/.config/conky/main.conf`:

- `alignment` — угол привязки: `top_right`, `top_left`, `bottom_right`, `bottom_left`, `top_middle`
- `gap_x`, `gap_y` — отступ от угла в пикселях

```bash
pkill conky && conky -c ~/.config/conky/main.conf &
```

### Плотность подложки виджета

```bash
sed -i 's/own_window_argb_value = .*/own_window_argb_value = 180,/' ~/.config/conky/main.conf
```

`0` — совсем прозрачно, `255` — сплошной фон. Дефолт `225`.

### Больше обоев

```bash
./modules/wallpapers.sh 20
```

Разрешение определяет само. Темы правятся в переменной `ALL` внутри скрипта — работает любой поиск wallhaven.

### Прозрачная панель

Настройки Dash to Panel → **Style** → `Panel background opacity` → `0`

Если панель на нескольких мониторах — настройки задаются **отдельно для каждого**, монитор выбирается на вкладке Position.

## Откат

Полностью убрать всё, что сделал скрипт:

```bash
gsettings reset-recursively org.gnome.desktop.interface
pkill conky
rm -rf ~/.config/conky ~/.config/autostart/conky.desktop
rm -rf ~/bin/{setwall,weather-line,conky-recolor,powermenu,wifimenu,pickcolor,cleanmeta}
rm -rf ~/.cache/wal ~/.cache/wall*
dconf reset -f /org/gnome/settings-daemon/plugins/media-keys/
```

Алиасы — вручную убрать блок `# --- bootstrap aliases ---` из `~/.bashrc`.

Пакеты остаются, они безвредны. Хочешь снести:

```bash
sudo apt purge -y conky-all rofi flameshot lsd bat ranger zathura calcurse gpick mat2
```

## Если что-то не работает

**Первое: смотри лог** `~/.cache/ubuntu-kit-bootstrap.log` — туда пишется всё, что скрыто с экрана.

**apt упал в самом начале** — на свежей системе первые минуты фоновые обновления держат менеджер пакетов. Скрипт ждёт до 10 минут сам; если не дождался — подожди и перезапусти.

**Расширения не поставились** — `extensions.gnome.org` бывает недоступен из корпоративных сетей. Ставь вручную через Extension Manager, он ходит другим путём.

**Обои не скачались** — проверь, что API отвечает:
```bash
curl -s "https://wallhaven.cc/api/v1/search?q=nature" | jq '.data | length'
```
Должно вернуть `24`.

**Виджет не видно** — запусти в терминале и посмотри вывод:
```bash
pkill conky; conky -c ~/.config/conky/main.conf
```

**Погода пустая** — проверь wttr.in:
```bash
curl "wttr.in/Moscow?format=3"
```

**Хоткеи не сработали** — проверь, что зарегистрировались:
```bash
gsettings get org.gnome.settings-daemon.plugins.media-keys custom-keybindings
```
Должен вывестись список из одиннадцати путей. Если пусто — перелогинься.

**Тема не применилась** — проверь, что она собралась:
```bash
ls ~/.themes | grep Tokyonight
```
Пусто — сборка упала, смотри лог (обычно не хватило `sassc` или не было сети для клона).

**Алиасы не работают** — перечитай конфиг:
```bash
source ~/.bashrc
```
