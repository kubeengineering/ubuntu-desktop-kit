# ThinkPad X13 Gen 2: проверка б/у и установка

Заметки под конкретную машину: X13 Gen 2 (16 ГБ RAM, 256 ГБ SSD), б/у из Китая. Общий порядок установки — в [основном README](../README.md), здесь — что проверить в подержанном ноутбуке и чем эта модель отличается.

## Что за машина

- Официально **сертифицирована под Ubuntu** — всё железо работает из коробки на 24.04
- Только встроенная графика (Intel Iris Xe или AMD Vega) — **NVIDIA нет**, значит галка «сторонние драйверы» при установке не критична, а свежая система войдёт в **Wayland** — bootstrap-скрипт предложит переключиться на Xorg, соглашайся
- Wi-Fi Intel AX200/AX201 — работает сразу
- Экран 13.3" 16:10, обычно 1920×1200 — скрипт сам определит и скачает обои под это разрешение
- ⚠️ **RAM распаяна** — 16 ГБ навсегда, не апгрейдится. Для терминалов, браузера и виртуалки хватает
- SSD заменяемый (M.2 NVMe, в X13 Gen 2 короткий формат 2242 — сверься при вскрытии), 256 ГБ на первое время достаточно, обои и система займут ~20 ГБ
- Отпечаток пальца в кнопке питания — на Linux работает через fprintd (включается после установки: Settings → Users → Fingerprint Login)

## Проверка б/у — три этапа

### Этап 1. До того как принял ноутбук (5 минут, без флешки)

Это проверки «вернуть продавцу, пока не поздно»:

1. **BIOS открывается без пароля.** Включи, долби `F1`. Если просит Supervisor Password — у бывшего корпоративного владельца остался замок, снять его без продавца почти невозможно. **Это причина вернуть ноутбук.**
2. В BIOS → Security → найди **Absolute Persistence (Computrace)** — статус должен быть `Disabled` или `Deactivated`, не `Enabled`/`Activated`. Активный — машина числится в корпоративной системе слежения.
3. BIOS → Security → **Secure Boot** и **Boot Order** редактируются? Если поля серые — снова замок.
4. Серийник на наклейке дна совпадает с BIOS (Main → Serial Number). Проверь его на [проверке гарантии Lenovo](https://pcsupport.lenovo.com/warranty) — заодно увидишь реальный возраст машины и страну продажи.
5. Внешний осмотр: винты дна не сорваны, экран без трещин, петли не болтаются.

### Этап 2. С загрузочной флешки, до установки (~40 минут)

Флешка уже готова по основному README — грузись в **Try Ubuntu** и проверяй железо, пока диск ещё не тронут:

**Память (главная проверка б/у):** перезагрузись, в меню GRUB выбери **Test memory (memtest86+)**. Один полный проход ~15–25 минут. Любая красная строка = возврат или торг на замену платы — RAM распаяна.

**SSD — здоровье и пробег:**
```bash
sudo apt update && sudo apt install -y smartmontools
```
```bash
sudo smartctl -a /dev/nvme0
```
На что смотреть:
| Поле | Норма | Тревога |
|---|---|---|
| `Percentage Used` | до 30% | >70% — диск изношен, закладывай замену |
| `Media and Data Integrity Errors` | 0 | любое ненулевое |
| `Power On Hours` | — | просто оцени пробег (8760 ч = год непрерывно) |
| `Critical Warning` | 0x00 | что угодно другое |

**Батарея:**
```bash
upower -i /org/freedesktop/UPower/devices/battery_BAT0 | grep -E "energy-full|capacity|cycle"
```
`capacity` — здоровье в процентах от заводской ёмкости. 80%+ — отлично для б/у, 60–80% — жить можно, ниже 60% — торгуйся на замену (~3–5 тыс. ₽).

**Экран:** открой в браузере полноэкранные заливки (набери в поиске «dead pixel test» или просто открой белую/чёрную/красную картинку) — ищи битые пиксели и засветы по краям на чёрном.

**Клавиатура:** открой текстовый редактор и прожми каждую клавишу, включая Fn-ряд. У ThinkPad из Китая бывает иероглифная гравировка — раскладка при этом обычная US.

**Остальное по мелочи:**
```bash
# камера:
cheese
# звук: щёлкни по динамику в панели → проверка колонок
# оба USB-C, оба USB-A, HDMI — воткни что-нибудь в каждый
# Wi-Fi и Bluetooth видят сети/устройства
```

**Температуры под нагрузкой (проверка кулера и пасты):**
```bash
sudo apt install -y stress s-tui && sudo s-tui
```
Нажми `s` (stress) и смотри 5 минут: до ~95°C с падением частот — норма для Tiger Lake, но если упирается в 100°C и троттлит сразу — пора менять пасту (или торг).

### Этап 3. После установки Ubuntu

1. **Обнови прошивки** — на б/у это важно, BIOS может быть трёхлетней давности:
```bash
fwupdmgr refresh && fwupdmgr get-updates
```
```bash
fwupdmgr update
```
ThinkPad отлично поддержан в LVFS — BIOS, прошивка SSD и отпечатка приезжают прямо так.

2. **Отпечаток пальца:** Settings → System → Users → Fingerprint Login. Если пальца нет в списке устройств — сначала `fwupdmgr update` (частая причина — старая прошивка сенсора).

3. Дальше по основному README: три команды — и десктоп готов. На вопрос про Xorg отвечай **y** — на этой машине NVIDIA нет, система войдёт в Wayland, а набор рассчитан на Xorg.

## Частые вопросы по этой модели

**Зарядка** — USB-C, любой Power Delivery блок от 45 Вт. Родной Lenovo не обязателен.

**Иероглифы на клавишах** — если приехала китайская гравировка: физически это та же ANSI/ISO клавиатура, в Ubuntu просто выбирай English (US) + Russian, гравировка ни на что не влияет.

**Спящий режим** — если из коробки просыпается мгновенно или жрёт батарею во сне: BIOS → Config → Power → **Sleep State** → переключи в `Linux` (S3). На Windows-режиме (Modern Standby) Linux спит хуже.
