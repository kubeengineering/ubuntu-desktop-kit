# Эталонная машина

Снимок настроенного десктопа, снятый `tools/desktop-audit.sh` **26.08.2026**. Это то состояние, которое раскатка должна воспроизводить на новом ноутбуке. Если `bootstrap.sh` расходится с этим файлом — прав этот файл: он списан с живой системы, а не с намерений.

Свой такой снимок делается одной командой: `design audit`. Он же — самый простой способ перенести настройку на другую машину.

## Расширения GNOME

Включены: `ding`, `dash-to-panel`, `user-theme`, `just-perfection`, `tiling-assistant` (штатный Ubuntu).

Выключены: `ubuntu-dock`, `Vitals`, `blur-my-shell`.

Про выключенные: `Vitals` падает без `gir1.2-gtop-2.0`, а пакет не установлен. У `blur-my-shell` панели назначен пустой конвейер `pipeline_77282580541832` без единого эффекта, так что размытия нет даже при включении.

Dash to Panel: панель на трёх мониторах, размер 51, длина 50 %, `trans-panel-opacity=0.0` при `trans-use-custom-opacity=true` — то есть полностью прозрачная подложка.

## Автозапуск

`conky` (с задержкой 5 с), `CopyQ` (общий буфер), `ktalk` (Толк, скрытым), `activate-linux`.

## Корпоративное — не ломать

Работают и от нашей настройки не зависят: `klnagent64` (Kaspersky), `vxagent` (MaxPatrol EDR), `antimal-ui` (PT). VPN `PTsecurity` через NetworkManager, поднимает `tun0`.

## Чего на машине нет

Не установлены и по факту не нужны: `gpick`, `xclip`, `mat2`, `lutgen`, `gext`, `yt-dlp`, `ffmpeg`, `lm-sensors`, `gir1.2-gtop-2.0`, `python3-pip`.

В `~/bin` всего четыре скрипта: `newtab`, `setwall`, `wallpapers`, `weather-line`. Скриптов `powermenu`, `wifimenu`, `pickcolor`, `cleanmeta`, `conky-recolor` нет — **`bootstrap.sh` на этой машине никогда не выполнялся**, всё настраивалось руками.

## Что из этого следует для раскатки

1. Убрать rofi и завязанные на него `powermenu` / `wifimenu`.
2. Хоткеи вешать на `Ctrl+Q` и клавиши цифрового блока, а не на `Super+R` / `Super+D`.
3. Ставить `gir1.2-gtop-2.0`, если Vitals нужен; иначе не ставить Vitals вовсе.
4. Добавить в раскатку: страницу новой вкладки, `setwall`, таймер обоев, светлую почту.
5. Не тащить `gpick`, `mat2`, `lutgen` — ими не пользуются.
