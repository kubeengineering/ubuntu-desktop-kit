# Chrome: своя новая вкладка

Часы, свои ярлыки и обои рабочего стола фоном — причём никогда та же картинка, что стоит на столе прямо сейчас. Фон запоминается между вкладками и перезапусками браузера, листается стрелками.

## 1. Собрать страницу

```bash
design newtab
```

Команда при первом запуске сам вытащит ярлыки из Chrome (кастомные плитки новой вкладки, Top Sites, закладки, а если мало — самые посещаемые из истории) в файл `~/.local/share/newtab/links.txt`. Базы копируются во временную папку, поэтому Chrome можно не закрывать.

Дальше список правится руками:

```bash
nano ~/.local/share/newtab/links.txt
```

Формат — по строке на ярлык:

```
ESXi|https://адрес
vCenter|https://адрес
YouTrack|https://адрес
```

После правки пересобрать — тем же вызовом `design newtab`.

## 2. Подключить к новой вкладке

Chrome не даёт подменить новую вкладку без расширения — это его защита, обойти нечем.

### Автоматически

```bash
bash legacy/chrome-policy.sh
```

Скрипт прописывает системную политику, которая ставит **Custom New Tab URL** и сразу задаёт ему адрес страницы. Нужен `sudo`, Chrome после этого надо перезапустить. Расширение скачивается из Web Store — если он недоступен из корпоративной сети, политика не сработает, и останется ручной путь.

### Вручную

1. Web Store → поставить **Custom New Tab URL** или **New Tab Redirect**
2. В настройках расширения указать:
   ```
   file:///home/ПОЛЬЗОВАТЕЛЬ/.local/share/newtab/index.html
   ```
3. `chrome://extensions` → у этого расширения **Details** → включить **Allow access to file URLs**

⚠️ Третий шаг обязателен. Без него будет **белый экран** — Chrome блокирует расширениям доступ к локальным файлам.

### Если расширения недоступны совсем

**Настройки → Запуск Chrome → Заданные страницы** и тот же `file://` адрес. Тогда страница встречает при старте браузера, а новая вкладка останется штатной.

⚠️ **Ценой восстановления сессии.** Три режима запуска взаимоисключающие: выбрав «Заданные страницы», теряешь «Ранее открытые вкладки», и Chrome начинает стартовать пустым. Если вкладки дороже — оставайся на расширении.

## Вкладки перестали восстанавливаться

Первое место:

```
chrome://settings/onStartup
```

Должно стоять **Continue where you left off**. Если там «Открывать заданные страницы» с `file://` адресом — это оно, переключай (страница новой вкладки идёт через расширение, стартовая ей не нужна).

Второе место:

```
chrome://settings/content/siteData
```

Пункт **Delete data sites have saved to your device when you close all windows** — при нём Chrome стирает сессию вместе с данными сайтов. В свежих версиях он именно здесь, а не в разделе cookie: `chrome://settings/cookies` теперь только про третьесторонние.

## 3. Управление

| Клавиша | Действие |
|---|---|
| `→` | следующая картинка |
| `←` | предыдущая |

Внизу слева на секунду всплывает счётчик вида `12 / 340`. Выбранная картинка хранится в `localStorage` и переживает перезапуск браузера — как закрепление обоев на рабочем столе.

## Шрифт

Страница использует **JetBrainsMono Nerd Font** — тот же, что в терминале. Ставится `bootstrap.sh`; если запускаешь модуль отдельно:

```bash
mkdir -p ~/.local/share/fonts
wget -qP /tmp https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.0/JetBrainsMono.zip
unzip -qo /tmp/JetBrainsMono.zip -d ~/.local/share/fonts/JetBrainsMono
fc-cache -f
```

## Размеры и цвета

Всё в `<style>` внутри `~/.local/share/newtab/index.html`, но правки затрутся при следующей пересборке. Чтобы менять насовсем — правь генератор `design newtab`:

| Что | Где искать |
|---|---|
| Часы | `.clock{font-size:110px` |
| Дата | `.date{font-size:24px` |
| Подписи плиток | `.cap{font-size:16px` |
| Размер плитки | `.tile{width:130px` |
| Иконки | `.ico{width:52px` |
| Плотность подложек | `rgba(0,0,0,.32)` |

Фоновый цвет берётся из палитры обоев автоматически — если стоит `pywal`, страница будет в тон рабочему столу.

## Иконки ярлыков

Берутся из локального кэша Chrome — файла `~/.config/google-chrome/Default/Favicons`. Это обычная база SQLite, куда браузер складывает значки всех сайтов, где ты бывал; скрипт достаёт самый крупный из них и вшивает прямо в страницу как `data:` URI. Поэтому внутренние адреса, которых не видно снаружи, показываются своими настоящими значками, а не заглушкой.

Если значка в кэше нет, страница пробует по очереди:

1. `https://адрес/favicon.ico` — прямо с самого сайта
2. сервис фавиконок Google
3. первая буква названия в квадратике

Значок появился в Chrome только что, а на плитке ещё заглушка — пересобрать страницу:

```bash
newtab
```

Сколько значков нашлось локально, скрипт печатает в конце работы.

## Пополнение картинок

Страница берёт картинки из того же банка, что и обои рабочего стола. Пополняется:

```bash
design wallpapers --count 10
```

После загрузки страница новой вкладки пересобирается автоматически.
