# Если что-то не работает

Сначала — три команды, которые отвечают на большинство вопросов:

```bash
design status                    что сейчас применено
design selftest                  быстрая проверка, ничего не меняет
tail -50 ~/.local/state/desktop-kit/desktop-kit.log
```

Лог самого `bootstrap.sh` живёт отдельно: `~/.cache/ubuntu-kit-bootstrap.log`. Туда попадает всё, что скрыто с экрана.

## Установка

**apt отказывается работать в самом начале.** Свежая Ubuntu первые минуты сама тянет обновления и держит блокировки. Скрипт ждёт до пятнадцати минут и говорит, чего ждёт. Если не дождался — посмотрите, кто держит: `ps aux | grep -E 'apt|dpkg'`.

**Расширения не поставились.** `extensions.gnome.org` бывает недоступен из корпоративных сетей и просто медленным. Поставьте вручную через Extension Manager — он ходит тем же путём, но с интерфейсом и повторами.

**Тема не собралась.** Проверьте, есть ли она на диске:

```bash
design theme --list | grep -i graphite
```

Пусто — сборка упала. Обычно не хватило `sassc` или оборвалась связь с GitHub: `design themes --install Graphite` покажет причину.

## Внешний вид

**Файловый менеджер не поменялся вместе с темой.** Так и есть: Nautilus написан на libadwaita, а он темы GTK игнорирует. Применяйте с флагом: `design theme ИМЯ --gtk4`. Подробности — в [gtk-theming.md](gtk-theming.md).

**Кнопки заголовка пропали после установки темы.** Установщик темы переписал `~/.config/gtk-4.0/gtk.css`. Лечится одной командой: `design refresh`. Скрипт замечает это сам и предлагает починку сразу.

**Кнопок не видно, хотя всё применилось.** Тема может рисовать их своей картинкой — тогда наши значки под ней. Проверить: `design themes --check ИМЯ`. Для таких тем есть режим `design buttons keep`.

**Виджет не появился.** На Wayland он стартует раньше XWayland и иногда не успевает. Проверьте руками:

```bash
pkill conky; conky -c ~/.config/conky/main.conf
```

Если ругается на дисплей — помогает перезаход в сессию.

**Погода в виджете пустая.** Виджет зовёт помощника, а тот ходит на wttr.in:

```bash
~/bin/weather-line
```

Пусто — сервис недоступен или город написан не латиницей. Поменять: `design widget --city Novosibirsk`.

**Панель не изменилась.** Убедитесь, что Dash to Panel вообще включён — без него команда `panel` меняет настройки расширения, которого нет:

```bash
gnome-extensions list --enabled | grep dash-to-panel
```

## Клавиши и оболочка

**Горячие клавиши не сработали.** Посмотрите, что зарегистрировано:

```bash
design keys
```

Если список пуст — `design keys --defaults`. Если непусто, а клавиша молчит, скорее всего сочетание занято самим GNOME: Settings → Keyboard → Shortcuts.

**Алиасы не работают.** Они добавляются в `.bashrc`, который читается при старте оболочки: `source ~/.bashrc` либо новый терминал.

## Когда проще откатить

```bash
design profile load before-look   вернуть вид, который был до образа
design revert                     всё, что мы когда-либо меняли
design revert --list              что именно запомнено и можно вернуть
```

`revert` возвращает состояние до нашего первого вмешательства и не трогает чужие правки в `gtk.css` — они переживают откат.
