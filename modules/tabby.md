# Tabby: прозрачность и вид

[Tabby](https://tabby.sh) — терминал на Electron, удобен для SSH: профили подключений, вкладки как в браузере, SFTP и проброс портов встроены. Ставится своим `.deb` с сайта, в репозиториях Ubuntu его нет.

Ниже — как довести его до вида «стеклянного» терминала. Всё настраивается в самой программе, скриптов не нужно.

## Прозрачность

**Settings → Window:**

| Пункт | Значение |
|---|---|
| **Acrylic background** | включить |
| **Opacity** | вправо, в максимум |
| **Disable GPU acceleration** (в блоке Hacks) | **выключено** |

Acrylic делает прозрачным само окно. Но область терминала внутри — отдельный слой (её рисует xterm), и она остаётся плотной. Поэтому дальше нужен CSS.

⚠️ `Disable GPU acceleration` прозрачность **ломает** — если включить, окно станет глухим.

## CSS для области терминала

**Settings → Appearance → Custom CSS:**

```css
.xterm-viewport,
.xterm-screen,
.terminal,
terminal-tab {
  background-color: rgba(26, 27, 38, 0.45) !important;
}
```

Применяется сразу, перезапуск не нужен.

**Регулировка** — последнее число: `0.30` сильно прозрачно, `0.55` умеренно, `0.85` почти плотно.

Цвет `26, 27, 38` — фон Tokyo Night. Под свою палитру возьми текущий фоновый цвет:

```bash
grep -m1 background ~/.cache/wal/colors.sh
```

и переведи hex в RGB.

## Почему именно эти селекторы

`.content` в Tabby **три штуки**, и это главная ловушка. По `appRoot.component.pug` вложенность такая:

```
.window
  profile-tree            ← боковая панель
  .content.main           ← корпус: в нём и плашка, и содержимое
    .tab-bar              ← плашка вкладок
      .tabs > tab-header
    .content              ← обёртка содержимого
      tab-body.content-tab
        terminal-tab
          .content        ← этот держит сам терминал
```

Поэтому голый `.content` в списке селекторов цепляет и `.content.main` — вместе с плашкой вкладок, и она тоже становится прозрачной.

`tab-body` добавлять **нельзя** — это содержимое вкладки, а не панель: закрасит весь терминал.

Плотную плашку задаёт отдельный блок:

```css
.tab-bar,
profile-tree {
  background: #16161e !important;
}
```

## Рамки вокруг терминала выглядят прозрачнее самого терминала

Полоса по краям вкладки — это `margin` самого Tabby, `baseTerminalTab.component.scss`:

```scss
:host > .content {
  margin: calc(max(0px, 30px * var(--spaciness) - 15px));
}
```

Терминал внутри несёт два слоя (стекло окна плюс фон xterm), а полоса — только стекло, оттого и бледнее.

**Ползунок Spaciness её убирает, но не только её** — та же переменная кормит `--tabs-height`, `--side-tab-width` и размеры SVG, так что «влево до упора» делает значки микроскопическими. Отступ снимается отдельно:

```css
/* терминал во всю вкладку, полосы нет */
terminal-tab > .content {
  margin: 0 !important;
}
```

```css
/* отступ на месте, но плотный — в цвет плашки */
terminal-tab > .content {
  margin: 0 !important;
  border: 15px solid #16161e !important;
}
```

`!important` обязателен: Angular компилирует `:host > .content` в атрибутные селекторы, и специфичность у оригинала выше.

## Чего сделать нельзя: плотный корпус при прозрачном терминале

Прозрачность терминала — сквозная дырка до обоев, поэтому всё под `.xterm` обязано быть прозрачным. Стоит закрасить `.content` или `tab-body` — сквозь терминал видно эту заливку вместо обоев, и прозрачность пропадает. Плотными можно делать только элементы **вне** цепочки предков терминала: `.tab-bar`, `profile-tree`.

## Плотность интерфейса

**Settings → Window → Spaciness** — ползунок отступов. Влево компактнее, вправо просторнее. На ultrawide имеет смысл сдвинуть влево, чтобы полоса вкладок не съедала высоту.

## Заголовок окна

**Settings → Window → Window frame:**

- `Native` — системный заголовок, кнопки как у остальных окон GNOME
- `Thin` — свои кнопки Tabby, тонкие, в стиле Windows
- `Full` — полная своя рамка

## Контраст на разных мониторах

Одна и та же прозрачность на двух мониторах может выглядеть по-разному — это разница в контрастности панелей, а не проблема настройки. Подбирай значение по тому монитору, где работаешь чаще.
