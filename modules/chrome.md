# Chrome: своя новая вкладка

Часы, свои ярлыки и обои рабочего стола фоном — причём никогда та же картинка, что стоит на столе прямо сейчас. Фон запоминается между вкладками и перезапусками браузера, листается стрелками.

## 1. Собрать страницу

```bash
./modules/newtab.sh
```

Скрипт при первом запуске сам вытащит ярлыки из Chrome (кастомные плитки новой вкладки, Top Sites, закладки, а если мало — самые посещаемые из истории) в файл `~/.local/share/newtab/links.txt`. Базы копируются во временную папку, поэтому Chrome можно не закрывать.

Дальше список правится руками:

```bash
nano ~/.local/share/newtab/links.txt
```

Формат — по строке на ярлык:

```
ESXi|https://адрес
vCenter|https://адрес
YouTrack|https://адрес
```

После правки пересобрать — тем же вызовом `./modules/newtab.sh`.

## 2. Подключить к новой вкладке

Chrome не даёт подменить новую вкладку без расширения — это его защита, обойти нечем.

### Автоматически

```bash
./modules/chrome-policy.sh
```

Скрипт прописывает системную политику, которая ставит **Custom New Tab URL** и сразу задаёт ему адрес страницы. Нужен `sudo`, Chrome после этого надо перезапустить. Расширение скачивается из Web Store — если он недоступен из корпоративной сети, политика не сработает, и останется ручной путь.

### Вручную

1. Web Store → поставить **Custom New Tab URL** или **New Tab Redirect**
2. В настройках расширения указать:
   ```
   file:///home/ПОЛЬЗОВАТЕЛЬ/.local/share/newtab/index.html
   ```
3. `chrome://extensions` → у этого расширения **Details** → включить **Allow access to file URLs**

⚠️ Третий шаг обязателен. Без него будет **белый экран** — Chrome блокирует расширениям доступ к локальным файлам.

### Если расширения недоступны совсем

**Настройки → Запуск Chrome → Заданные страницы** и тот же `file://` адрес. Тогда страница встречает при старте браузера, а новая вкладка останется штатной.

## 3. Управление

| Клавиша | Действие |
|---|---|
| `→` | следующая картинка |
| `←` | предыдущая |

Внизу слева на секунду всплывает счётчик вида `12 / 340`. Выбранная картинка хранится в `localStorage` и переживает перезапуск браузера — как закрепление обоев на рабочем столе.

## Шрифт

Страница использует **JetBrainsMono Nerd Font** — тот же, что в терминале. Ставится `bootstrap.sh`; если запускаешь модуль отдельно:

```bash
mkdir -p ~/.local/share/fonts
wget -qP /tmp https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.0/JetBrainsMono.zip
unzip -qo /tmp/JetBrainsMono.zip -d ~/.local/share/fonts/JetBrainsMono
fc-cache -f
```

## Размеры и цвета

Всё в `<style>` внутри `~/.local/share/newtab/index.html`, но правки затрутся при следующей пересборке. Чтобы менять насовсем — правь генератор `modules/newtab.sh`:

| Что | Где искать |
|---|---|
| Часы | `.clock{font-size:110px` |
| Дата | `.date{font-size:24px` |
| Подписи плиток | `.cap{font-size:16px` |
| Размер плитки | `.tile{width:130px` |
| Иконки | `.ico{width:52px` |
| Плотность подложек | `rgba(0,0,0,.32)` |

Фоновый цвет берётся из палитры обоев автоматически — если стоит `pywal`, страница будет в тон рабочему столу.

## Иконки ярлыков

Подтягиваются с сервиса фавиконок Google по домену. Для внутренних адресов, недоступных снаружи, вместо картинки показывается первая буква названия в квадратике — так что список внутренних ресурсов выглядит опрятно, а не сломанно.

## Пополнение картинок

Страница берёт картинки из того же банка, что и обои рабочего стола. Пополняется:

```bash
./modules/wallpapers.sh 10
```

После загрузки страница новой вкладки пересобирается автоматически.
