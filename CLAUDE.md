# Правила работы с этим проектом

Грузится только при работе в этом каталоге, поэтому другие чаты за него не платят.

## Не читать `desktop-kit.sh` целиком

9621 строк, ~380 КБ, **~92 тысячи токенов за одно чтение**. Замерено: файл читали
12 раз, и каждое чтение оседает в контексте — дальше он пересылается в КАЖДОМ
следующем запросе, пока контекст не сожмётся. Это 22% всего окна из одного файла,
и именно отсюда тормоза этого чата.

**Порядок работы:**

1. Открыть [SCRIPT-MAP.md](SCRIPT-MAP.md) — карта на ~2 тысячи токенов: функции,
   секции и команды с номерами строк.
2. Найти нужное место по карте.
3. Прочитать точечно: `Read` с `offset` и `limit` на 40–80 строк вокруг.

Разница: 2 тыс. токенов вместо 92 тыс. — **в 46 раз дешевле**.

В карте первым делом раздел **«Рецепты: что где править»** — таблица «задача →
функция и строка». В большинстве случаев дальше искать не нужно.

Карта пересобирается после крупных правок генератором из этого же репозитория:

```bash
bash tools/make-map.sh > SCRIPT-MAP.md
```

## Искать, а не листать

Нужное место ищется `Grep` по имени функции или строке сообщения, а не чтением
подряд. `Grep` возвращает номера строк, дальше точечный `Read`.

## Правки

Точечный `Edit` по найденному фрагменту. Не переписывать файл целиком через
`Write` — это и дорого, и рискованно на 7 тысячах строк.

## Структура репозитория

```
desktop-kit.sh     главный скрипт, всё в одном файле
bootstrap.sh       раскатка с нуля на свежей системе
docs/              документация, каждая тема отдельным файлом
tools/             design (запускалка), генератор карты, быстрая проверка
tests/             старые наборы тестов; основные живут внутри selftest
legacy/            скрипты-предшественники, оставлены как есть
```

## Стоит подумать о разделении

9621 строк в одном bash-файле — проблема не только для агента. Разнести по модулям
имеет смысл, но это отдельная задача: сначала тесты (`selftest --full`), потом
разделение. Предшественники лежат в `legacy/` и не развиваются.
